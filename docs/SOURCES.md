# Local content sources

Curated October 17, 2026. Information is summarized in original wording; no external imagery is copied. The SVG coast illustration and logo are original project assets. Map locations are schematic.

| Source | Used for |
| --- | --- |
| [PVE Recreation](https://www.pvestates.org/services/recreation) | Farnham Martin Park, Lunada Bay Plaza, and Paseo Del Mar bluff paths |
| [PVLD Locations](https://www.pvld.org/locations) | Malaga Cove, Peninsula Center, and Miraleste libraries |
| [PVLD Services](https://www.pvld.org/services) | General library services |
| [Point Vicente visitor information](https://www.rpvca.gov/1204/Visit-Point-Vicente-Interpretive-Center) | Interpretive center and local history |
| [Vicente Bluffs Reserve](https://www.rpvca.gov/1158/Vicente-Bluffs-Reserve) | Reserve description and official access resources |
| [PVLD Volunteering](https://www.pvld.org/volunteer) | Ages 14+, application requirement, used-book room role |
| [PVLD Events](https://pvld.libnet.info/events) | Official calendar link |
| [PVE website](https://www.pvestates.org/) | City calendar and announcements starting point |
| [PVPLC](https://pvplc.org/) | Official conservation and volunteering starting point |

No opening hours or dated public events are duplicated because they can change. The conservation card links to the organization rather than claiming a current opening or a scheduled volunteer day. Personal events are created by the user, not presented as verified public events.

To update the directory, edit `dist/data.js`, verify the official source, run `python3 scripts/build.py`, then run the checks and tests. Keep the curation date current after review. Visit durations are product planning estimates, not official source claims.
